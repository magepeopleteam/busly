Busly Documentation

Everything you need to install, configure and customize the Busly bus-booking theme.

Installation

Upload busly.zip under Appearance → Themes → Add New → Upload Theme, then click Activate. Busly requires PHP 8.0+ and WordPress 6.0+.

Theme Activation

After activation you'll see a "Busly" item in the admin menu. Open Busly → Setup Wizard to walk through required plugins and demo import, or go straight to Busly → Theme Settings if you'd rather configure everything by hand.

Required Plugins

  • Elementor — required. Powers the 100%-editable homepage and every Busly widget.
  • Bus Ticket Booking with Seat Reservation — required for search, seat maps and bookings. Distributed outside WordPress.org, so install its ZIP manually if you don't already have it.
  • WooCommerce — optional for the theme itself, but required by the booking plugin for search results, seat selection and checkout to function (this is a limitation of the booking plugin, not Busly).
Busly → Dashboard and Busly → Setup Wizard both show live status (Active / Installed but Inactive / Not Installed) for all three, with one-click install/activate for the two that are on WordPress.org (Elementor, WooCommerce).

Elementor Setup

Once Elementor is active, every Busly widget appears under its own Busly category in the Elementor panel. Edit the homepage directly from Busly → Dashboard → Edit Homepage, or from Pages → Home → Edit with Elementor.

Each widget supports Elementor's native Style tab (typography, colors, background, border, shadow, spacing) and responsive Desktop/Tablet/Mobile controls — nothing is hard-coded.

Bus Booking Setup

Manage buses, routes, seat plans and pricing under Buses in wp-admin (added by the booking plugin). Busly never modifies this plugin — it only:

  • Restyles the plugin's real search form, results cards, seat map and single-bus page via assets/css/booking.css, targeting the plugin's own CSS classes.
  • Overrides exactly two plugin templates that contain zero business logic (see templates/README.md) to fit the theme's header/footer.
  • Ships a Busly Bus Search and Busly Bus Listing Elementor widget that render the plugin's own shortcodes.

My Account gets a "Bus Booking Dashboard" tab automatically (added by the plugin) once WooCommerce is active.

WooCommerce Setup

If you activate WooCommerce, Busly automatically styles the shop, product pages, cart, checkout and account pages — no setup required. Configure grid columns and sidebar layout under Busly → Theme Settings → WooCommerce.

Demo Import

Busly → Setup Wizard → Demo Import creates: Home, About Us, Contact, FAQ, Terms & Conditions, Privacy Policy and Blog pages, a Primary + 3 footer navigation menus, the Elementor homepage layout, and applies sensible Theme Settings defaults. It is safe to re-run: existing pages/menus are detected and re-used, never duplicated or overwritten.

Homepage Setup

The Setup Wizard sets the demo "Home" page as your static front page automatically (Settings → Reading). To build your own homepage from scratch instead, create a new Page, edit it with Elementor, add Busly widgets from the "Busly" category, then set it as your front page.

Header Setup

Menus: Appearance → Menus, assign a menu to "Primary Menu". Sticky/transparent header behaviour: Customizer → Busly Options → Header Behavior. Login/My Bookings/Book Now buttons: Busly → Theme Settings → Header.

Footer Setup

Footer columns use widget areas (Appearance → Widgets → Footer Column 1/2/3) if populated, otherwise fall back to nav menus assigned to the "Footer — Company/Travel/Support" locations. Social links and copyright text: Customizer → Busly Options.

Theme Settings

Busly → Theme Settings is organized into General, Header, Typography, Colors, Footer, Blog, Bus Booking, WooCommerce, Performance and Social tabs. Every color/radius/container-width setting is written out as a CSS custom property (--busly-primary, etc.) so the whole design system updates instantly.

Troubleshooting

  • Seat map looks unstyled: confirm the page/widget is detected by busly_should_load_booking_assets() — if you embedded the search/listing shortcode somewhere unusual, hook add_filter('busly_force_load_booking_assets', '__return_true').
  • Search/booking doesn't work at all: WooCommerce must be active — this is required by the booking plugin itself.
  • Homepage is blank: run Busly → Setup Wizard → Demo Import, or build a page in Elementor and set it as your static front page.
  • A plugin update changed booking markup: only assets/css/booking.css needs a follow-up patch — no booking logic lives in the theme.

Translation

Text domain: busly. A starter languages/busly.pot is included. Translate with Loco Translate, Poedit, or WPML/Polylang's string translation.

Child Theme Usage

Busly is fully child-theme friendly. Override any template by copying it into your child theme at the same path. Use the documented busly_before_* / busly_after_* action hooks (see PHASE 40 in the build brief, or grep inc/template-hooks.php) to inject markup instead of editing parent files.
